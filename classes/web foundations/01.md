# Introduction to HTML

## Section: HTML Tags

### Summary

- Every website is a text file.
- For the text file to open in Chrome, we need to save it with the `.html` extension.
- If the `.html` or `.txt` extension is not showing in your Windows, you can enable it by opening your documents folder → view menu → file name extensions.
- The browser doesn't understand plain text, we need to use a language it understands. That language is HTML.
- An HTML tag is written like this:
```jsx
<tag>...</tag>
```
- Your first tags:
```html
<h1>Titles and subtitles (h1 to h6)</h1>
<p>Paragraph</p>
<strong>Bold</strong>
<em>Italic</em>
```
- Besides Notepad, you can (and should!) use a code editor. An example is [vscode](https://code.visualstudio.com/) or online editors like [codesandbox.io](https://codesandbox.io/)

## Section: Attributes

### Summary

- Some tags accept specific configurations about how they should work. For example, a link needs the configuration of the destination address. This is indicated using **attributes**, in this way:
```jsx
<tag attribute="value">...</tag>

For example, a link:
<a href="https://google.com" target="_blank">Go to Google</a>
```    
- Another tag that needs configuration is the `<img>` tag, which needs the `src="..."` attribute to indicate the image address:
```html
<img src="my_photo.jpg">
```
- Note that some tags break the rule of `<tag>...</tag>` because they don't need to be closed. For example: the `<img>` and `<br>` tags don't make sense to be closed, because an image or a line break doesn't have a beginning and an end.
