# Flex, justify content and align items

## Section: Block vs Inline, Flex, Flex wrap

### Summary
There are 2 types of elements in HTML: elements that take the entire line for themselves (block) and elements that share the line with other elements (inline)
Some examples are:
Block: `<h1>`, `<p>`, `<div>`
Inline: `<strong>`, `<em>`, `<a>`
When we have two block elements next to each other, even though the width of them is small enough to fit side by side on the screen, this will not happen because block elements always break a line at the end of the element:
```html
/* Even though the width of them is small */

.caixa {
	width: 30px;
}
​
<div class="caixa">Essa ficará em cima</div>
<div class="caixa">Essa ficará embaixo</div>
```
​
Many times we want to put side by side elements that are originally block, that is, we don't want them to break line
One way to do this is to use a CSS feature called Flexbox
To do this, we need to wrap the elements inside a parent div that has the flexbox enabled, like this:
```css
.container {
	display: flex;    /* Enables flexbox inside the container div */
}

.box {
	width: 30px;
}
```
```html
<div class="container">
	<div class="box">This will be on the left</div>
	<div class="box">This will be on the right</div>
</div>
```
- On the other hand, elements inside a `flexbox`, by default, never break line, even if they don't fit in the parent element. When they pass the size of the parent, they are squeezed to fit (which is usually not what you want).
- One way to change this to allow line breaks when they don't fit in the parent is to configure the `flexbox` of the parent with the `flex-wrap` property, like this:
```css
.parent-element {
	display: flex;
	flex-wrap: wrap;
}
```

## Section: Justify content and align items

### Summary
- By default, inside a flexbox, items are organized from left to right and from top to bottom. However, many times we want to change this positioning.
- For example, we might want the items to be centered both horizontally and vertically
- To change the **horizontal distribution** of items inside the flexbox, we can use the `justify-content` property, like this:
```css
.parent-element {
	display: flex;
	justify-content: center; /* Some other options: flex-start, flex-end, space-between, space-around, space-evenly */
}
```
- Don't forget to experiment with the other options of `justify-content` besides the `center`, since they are very powerful for layout construction!
- To change the **vertical distribution** of items inside the flexbox, we can use the `align-items` property, like this: 
```css
.parent-element {
	display: flex;
	align-items: center; /* Some other options: flex-start, flex-end */
}
```
