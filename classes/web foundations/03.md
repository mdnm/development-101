# CSS Classes, Backgrounds and CSS Resets

## Section: CSS Classes

### Summary

- When we use the tag selector (`p { ... }`), a consequence is that all paragraphs on our page will receive that style
- However, we may want some paragraphs to be styled differently.
- To solve this, look at the approach below:
```html
<html>
	<head>
	  <style>
	    .red-text { color: red; }
			.blue-text { color: blue; }
	  </style>
	</head>
	<body>
		<p class="red-text">My red paragraph</p>
		<p class="blue-text">My blue paragraph</p>
	</body>
</html>
```
- Notice that we are adding a `class` attribute with the values `red-text` or `blue-text` to the two paragraphs and then applying style to these identifiers inside the `style` tag
- This is a feature called **classes**. Classes are identifiers that you can add to HTML elements (using the `class` attribute) so that you can later apply styles to all elements that have that identifier
- Notice that when referencing classes in CSS, we need to start the selector with a **dot** (ex: `.red-text` for the class `red-text`). This dot **should not** be placed inside the `class="red-text"` attribute
- An element can have more than one class, just separate them with a space inside the class attribute:
```html
<html>
	<head>
	  <style>
	    .red-text { color: red; }
			.blue-text { color: blue; }
			.bold-text { font-weight: bold; }
	  </style>
	</head>
	<body>
		<p class="red-text">My red paragraph</p>
		<p class="blue-text bold-text">My blue and bold paragraph</p>
	</body>
</html>
```
- Finally, the same class can be applied to different types of elements at the same time, for example, in a p and h1:
```html
<html>
	<head>
	  <style>
	    .red-text { color: red; }
	  </style>
	</head>
	<body>
		<h1 class="red-text">My red heading</h1>
		<p class="red-text">My red paragraph</p>
	</body>
</html>
```
- If an element has conflicting styles applied both by the tag name and by a class, the final style will be the one of the class:
```html
<html>
	<head>
	  <style>
	    p { color: red; }
			.blue-text { color: blue; }
	  </style>
	</head>
	<body>
		<p>This paragraph will be red</p>
		<p class="blue-text">This paragraph will be blue</p>
	</body>
</html>
```

## Section: Backgrounds and CSS Resets

### Summary

- You can change the background color of an element using the background-color property:
```css
background-color: blue;
```
- You can get the color of a website or image using **color picker** tools. There are several browser extensions that do this, for example: **ColorZilla**. Or design tools like Figma.
- To represent an exact color, instead of the color name you can use the hexadecimal code that represents that color, for example: **red** is the same as the code **#FF0000**
- The browser already applies default styles to various elements (remnants from a time when CSS didn't exist!). For example, h1 has a large font and the body comes with a default margin. One way to remove these default styles that the browser applies is to use a technique called CSS Reset. This is useful so that your styles are more predictable, as an element will only have a style if you define it yourself.
- A CSS Reset file is a way to remove the default styles of the browser so that your styles are more predictable. Search for CSS Reset on Google and you will find several options.
- Another way to apply styles to a page is by using an **external CSS file**, through the `<link>` tag, as shown below:
```html
<head>
  <link rel="stylesheet" href="styles.css">
</head>
```
- Your styles.css file should contain direct CSS code, without the `<style>` tag, like this:
```css
p {
  color: red;
}
```
