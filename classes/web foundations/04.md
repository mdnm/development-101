# CSS Pillars, Cheat Sheets, Divs and dimensions

## Section: CSS Pillars and Cheat Sheets

### Summary

- We can divide CSS into 3 main responsibilities:
    1. **Formatting** (colors, fonts, backgrounds)
    2. **Dimensions** (width, height, margins, borders)
    3. **Positioning** (how to position elements on the screen)
- A quick way to look up existing CSS properties is to search for "CSS cheatsheet" on Google Images. Cheatsheets are one-page summaries of a topic, and they're very useful for many software development topics.

## Section: Divs and dimensions
- To apply layout on the web, we need to create boxes, position them where we want and add content inside them
- To make boxes, we use the `<div>` tag
- By default the `<div>` tag will have 100% width and height according to its content
- To change the width and height of an element, we can use the `width` and `height` properties respectively
- To space elements apart from each other, we can use the properties `margin-top`, `margin-right`, `margin-bottom` and `margin-left`
- There are some more practical ways to define margins of an element without having to define 4 properties, using only the `margin` property, like this:
```css
/* If all margins are equal, you can define only one margin: */
div {
	margin: 10px;
}

/* If the pairs top/bottom and left/right are equal, you can specify only 2 values: */
div {
	margin-top: 10px;
	margin-bottom: 10px;
	margin-right: 20px;
	margin-left: 20px;

	/* It's the same as, first top/bottom, then left/right: */
	margin: 10px 20px;
}


/* If the 4 values are different, you can still do: */
div {
	margin-top: 10px;
	margin-right: 20px;
	margin-bottom: 30px;
	margin-left: 40px;

	/* It's the same as, starting with the top and going clockwise: */
	margin: 10px 20px 30px 40px;
}
```
