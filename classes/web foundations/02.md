# HTML structure and introduction to CSS

## Section: HTML structure

### Summary

- This is the basic structure of an HTML file:
```jsx
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My title</title>
  </head>
  <body>
		<!-- This is a comment and won't be displayed in the browser -->
  </body>
</html>
```
- The `<!DOCTYPE html>` declaration is not a tag. It is an instruction to the browser about the version of HTML used in the document. In this case the most recent version, HTML5.
- The `lang="en"` attribute in the `<html>` tag indicates that the document is written in English. This is important for SEO (Search Engine Optimization) and accessibility.
- The `<meta charset="utf-8">` tag indicates that the document is encoded using the UTF-8 character set. This is important for displaying special characters correctly in older browsers.
- Notice that the file has a specific indentation to make the code more readable, so you understand the hierarchy of the elements.
- You can use the `<!-- ... -->` syntax to write comments in the code. These comments are not displayed in the browser. Usually helpful to explain the code or leave notes for yourself or others, but ideally the code should be self-explanatory.

## Section: Introduction to CSS

### Summary

- To change the style of a webpage, we need of something called CSS.
- One of the places we can write CSS is in the `<style>` tag in the `<head>` section of the HTML file.
```html
<html>
	<head>
		<style>
			HERE GOES THE CSS CODE
		</style>
	</head>

	<body>

	</body>
</html>
```
- To apply styles to a specific element, we need a way to tell CSS:
```markdown
I WANT THE <p> ELEMENT TO BE BLUE
```
- To do this, we can simply do:
```css
p {
	color: blue;
}
```
- So the complete code would be:
```html
<html>
	<head>
		<style>
			p {
				color: blue;
			}
		</style>
	</head>
	<body>
		<p>THIS TEXT WILL BE BLUE</p>
	</body>
</html>
```
- This `p` behind the curly braces is called a **selector** because it selects the element we want to style. In this case all `<p>` elements will be blue.
- Inside the curly braces we can add many attributes (ex: `color`) with their respective values (ex: `blue`).
- Note that at the end of the attribute we added a semicolon (`;`). CSS needs this to know that the attribute definition is finished.
- We can add multiple attributes at the same time:
```css
p {
	color: blue;
	font-family: Arial;
}
```
- Inside the `<style>` tag we can add multiple selectors and attributes.
```html
<html>
	<head>
		<style>
			p {
				color: blue;
				font-family: Arial;
			}

			h1 {
				color: red;
			}
		</style>
	</head>

	<body>
		<p>THIS TEXT WILL BE BLUE</p>
		<h1>THIS TEXT WILL BE RED</h1>
	</body>
</html>
```
- Here are some properties to change the style of a text:
```css
color: red;                       /* Text color */
font-family: Arial;               /* Font */
font-size: 20px;                  /* Font size */
font-weight: bold;                /* Boldness */
font-style: italic;               /* style, usually italic */
text-decoration: underline;       /* decoration, usually underline */
text-transform: uppercase;        /* transform into uppercase, lowercase or capitalize */
```
