# Responsive design and relative units

## Section: Responsive design and relative units

### Summary

- When we define a `width` based on percentage, this calculation is relative to the **parent** of the element, not the window, that is:    
```css
.parent {
  width: 500px;
}

.child {
  width: 50%; /* Will have width of 250px */
}
``` 
- To make a website responsive, we can follow three principles:
- Use relative sizes (`%` instead of `px`)
- Adjust the layout/position of elements with the flexbox (`flex-wrap: wrap`, change the `flex-direction`, change the values of `justify-content` and `align-items`)
- Make fine adjustments to font sizes and hide elements (`display: none`)
