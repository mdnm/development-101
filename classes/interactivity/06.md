# Arrays and while loops

## Section: Arrays

### Summary

When we need to store multiple related data in JavaScript, we can use an array:

```js
const tasks = ["First task", "Second task"];
```

To access the values of an array, we use the square brackets with the index of the item we want (starting at 0):
```js
const tasks = ["First task", "Second task"];
alert(tasks[0]); // First task
alert(tasks[1]); // Second task
```

We can also insert items into an array using the index:
```js
const tasks = [];
tarefas[0] = "Primeira tarefa";
tasks[1] = "Second task";
```

In addition to the syntax above, we can still insert items into an array using the push function, which always adds the item to the end of the array without the need to know the last index:
```js
const tasks = [];
tasks.push("First task");
tasks.push("Second task");
```
Finally, we can still discover how many items exist in an array by accessing the length property:
```js
const tasks = ["First task", "Second task"];
alert(tasks.length); // 2
```

## Section: While loops

### Summary

To execute the same code multiple times, we can use a loop structure in JavaScript. One of them being the `while` loop:
```js
while (condition) {
  // code
}
```

While the condition inside the while is true, it will execute the code inside the curly braces in loop. For example, if we wanted to execute the code 10 times printing from 0 to 9, we could do:

```js
let current = 0;

while (current < 10) {
	alert(current);
	current = current + 1;
}
```

We can simplify the way we do operations through increments:

```js
let current = 1;

current += 5; //6
current++; // returns 6 - current = 7
current *= 2; //14
current /= 2; //7
```
