# Variables, strings e concatenation, numbers, data types, operators and conditions

## Section: Variables, strings e concatenation

### Summary
- You can store values in JS using variables
- To define a variable, we can use `let`, like this:    
```jsx
let variableName = "blabla";
``` 
- You can use the value stored in the variable elsewhere by using its name, like this:    
```jsx
let birthYear = prompt("What year were you born?");
// ...
alert(birthYear);
```
- To join texts in JavaScript, we can use the addition operator (concatenate) between two texts, like this:    
```jsx
let message = "My name is " + "John"
alert(message); //My name is John
```
- You can also join texts with variables and variables with variables, for example:    
```jsx
let name = "John";
let message = "My name is " + name;
alert(message); //My name is John

// or

let beginning = "My name is ";
let name = "John";
let message = beginning + name;
alert(message); //My name is John
```
- Additionally, you can declare variables that never change value with `const`:    
```jsx
const answer = 42;
```
- `const` variables can be used the same way as `let` variables, with the exception that they cannot change value:
```jsx
const name = "John";
const message = "My name is " + name;
alert(message);

name = "Mary"; // not allowed!
```

## Section: Numbers, data types, operators

### Summary
- There is more than text variables in JS. There are also numbers. Text variables are called `string`. Integers are called `number`.
- To define a string and a number:
```jsx
const aString = "my string";
const aNumber = 123;
```
- A way to check the type of a variable (if it is `string` or `number`) is to use the `typeof` function, like this:
```jsx
const aString = "my string";
const aNumber = 123;

typeof(aString); // "string"
typeof(aNumber); // "number"
```
- When two values are `string`, the `+` operator joins the strings (**concatenation**), when the values are `number` it sums them:    
```jsx
5 + 0 //5
"5" + "0" //"50"
```
- We can convert a `string` to a `number` using `parseInt(myString)`. When it is not possible to make the conversion, we will get the result `NaN` (Not-a-Number)    
```jsx
const aString = "2000"; // string "2000"
const aNumber = parseInt(aString); // number 2000
```
```jsx
const aText = "I'm learning JS"; // string "I'm learning JS"
const aNumber = parseInt(aText); // NaN
```
- Mathematical operators:
    - `3 + 2` ⇒ 5 (sum)
    - `3 - 2` ⇒ 1 (subtraction)
    - `3 * 2` ⇒ 6 (multiplication)
    - `3 / 2` ⇒ 1.5 (division)
    - `3 % 2` ⇒ 1 (rest or modulus)
    - `3 ** 2` ⇒ 9 (exponentiation)
- The order of operations follows the same order as mathematics, so in the case of `3 + 2 / 2`, it would be 4 because the division will occur before the addition. We can change this behavior using parentheses: `(3 + 2) / 2` would now give 2.5

## Section: Conditions

### Summary
- You can control the execution of parts of your code based on conditions, using the if/else structure:    
```jsx
if (condition) {
  // Code executed when the condition is true
} else {
  // Code executed when the condition is false
}
``` 
- If you don't need the else, you can suppress it like this:    
```jsx
if (condition) {
  // Code executed when the condition is true
}
```
- In the condition you can make various types of comparisons. For example:    
```jsx
20 > 10 // Greater
20 >= 20 // Greater or equal
20 <= 20 // Less or equal
20 < 20 // Less

20 === 20 // Same value and same type
20 == "20" // Same value (regardless of type)

"20" !== 20 // True, considering the type
"20" != 20 // False, regardless of type
```
- To make comments in your JS code, you can do:    
```jsx
// single line comment

/*
multi-line
comment
*/
```
