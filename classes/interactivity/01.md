# Introduction to Javascript, onclick and functions

## Section: Introduction to Javascript

### Summary
- There is an easy place where you can write and run JavaScript code, which is the browser Console
- To open the Console in Chrome, use Ctrl+Shift+J or press F12 and select the **Console** tab
- To execute a command in JS, you need to use the command name followed by opening and closing parentheses: `command()`
- We can display a message to the user using the `alert()` command or ask for information from the user using the `prompt()` command
- You can put JavaScript code in your HTML using the `<script> ... </script>` tag (before closing the `body`)
- You can put your JS in external files using the src attribute: `<script src="scripts.js"></script>`

## Section: onclick and functions

### Summary

- You can execute a JS command from a user click, using the `onclick` attribute: `<div onclick="prompt()"></div>`
- What we call "commands" in JS (like `prompt` and `alert`) are actually functions (`function`)
- You can create your own function, which does what you want, using the following structure:
```js
function functionName() {
  ...
}
```
- And call them like this:
```js
functionName();
```
