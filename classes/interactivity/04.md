# Functions, parameters and return, Scopes and global variables, Terminal commands

## Section: Functions, parameters and return

### Summary
- As we saw, functions are pieces of code that can be executed whenever we want. For example:
```js
function myFunction() {
// lots of cool code
}

myFunction(); // your cool code will be executed
```
- A very important feature of functions is that you can pass values into them when calling. These values behave like variables inside the function. For example, below we're creating a parameter called `birthYear` and using it to calculate age:
```js
function showAge(birthYear) {
const age = 2021 - birthYear;
alert(age);
}

showAge(1992);
```
- Notice that in the function definition `function showAge(birthYear)` we use parentheses to define a name for the value it will receive. Then, when calling the function, we pass that value: `showAge(1992)`
- Inside the function, the `birthYear` variable is available to use however you want. It behaves like a regular variable.
- You can also pass more than one value, just separate them with commas:
```js
function showAge(currentYear, birthYear) {
const age = currentYear - birthYear;
alert(age);
}

showAge(2021, 1992);
```
- Finally, just like you can pass values into a function, you can also return values from it. For example:
```js
function calculateAge(birthYear) {
const result = 2021 - birthYear;
return result;
}

const age = calculateAge(1992);
alert(age);
```
- Just use the `return` keyword followed by the value you want the function to return, and you can then use this value later, for example by assigning it to a variable.
- When using `onclick` on an element to run a function, it's common to want to access the HTML element that was clicked. There's an easier way to do this without `document.querySelector`, using a feature called `this`, like this:
```html
<div onclick="doSomething(this)">...</div>

<script>
function doSomething(element) {
// element will be the clicked <div>, just like if selected with querySelector
console.log(element);
}
</script>
```
- A less "loud" way of showing alerts is using `console.log()`, so we can display messages only in the console:
```js
console.log("I'm a super cool message"); // Log
console.warn("I'm a warning message!!!"); // Warning - yellow
console.error("I'm an error message!!!"); // Error - red
```

## Section: Scopes and global variables

### Summary
- When you create a variable **inside** a function, it is **not accessible** outside of it. For example:

```javascript
function myFunction() {
  const myVariable = 10;
}

alert(myVariable); // myVariable does not exist here! Only inside the function
```

- This happens **even if you call the function**:

```javascript
function myFunction() {
  const myVariable = 10;
}

myFunction();

alert(myVariable); // myVariable still does not exist here! Only inside the function
```

- Variables created **inside functions** are called **local variables** because they are only accessible within the function.
- So, if you need to pass values into or out of a function, you should use **parameters** and **return**. For example:

```javascript
function myFunction() {
  const myVariable = 10;
  return myVariable;
}

const returnedValue = myFunction();

alert(returnedValue); // will alert 10
```

- On the other hand, variables declared **outside** of functions can be accessed and modified inside functions in the same script:

```javascript
const myVariable = 10;

function myFunction() {
  alert(myVariable);
}

myFunction(); // will alert 10
```

- These are called **global variables**, since they can be accessed from anywhere.
- Using too many global variables leads to problems in larger programs (you may have heard "don't use global variables!"). Don't worry about this now — just learn how they work and use them in your project as needed.
- You can even **modify** them from inside a function:

```javascript
let myVariable = 10;

alert(myVariable); // alerts 10

function myFunction() {
  myVariable = 20;
}

myFunction();

alert(myVariable); // alerts 20
```

- In other words, we changed the variable from 10 to 20 inside the function, and even outside, it has the new value.
- When we create a variable and don’t assign an initial value, it will be `undefined`:

```javascript
let coolVariable;
console.log(coolVariable); // undefined
```

- Variables declared with `var` can lead to unexpected behavior for two reasons:

  - **Reason 1** – They exist outside of blocks `{ }`:

```javascript
// Example with var
function hello() {
  var count = 2;
  if (count > 1) {
    var sayHello = "Hi";
  }
  console.log(sayHello); // "Hi"
}

// Example with let
function hello() {
  var count = 2;
  if (count > 1) {
    let sayHello = "Hi";
  }
  console.log(sayHello); // Error: sayHello is not defined
}
```

  - **Reason 2** – They can be re-declared:

```javascript
// Example with var
function hello() {
  var sayHello = "Bye";
  var sayHello = "Hi";
  console.log(sayHello); // "Hi"
}

// Example with let
function hello() {
  let sayHello = "Bye";
  let sayHello = "Hi"; // Error: sayHello has already been declared
  console.log(sayHello);
}
```

## Section: Terminal commands

### Summary
- Before graphical interfaces and mice, users interacted with computers through a text interface called the **Terminal**.
- Just like on the desktop, we can run programs in the terminal. For example, running the command `dir` lists the files and folders in the current directory.
- Each operating system has different terminals:
  - On **Windows**, we will use the **Git Bash** terminal. This terminal is installed along with [Git](https://git-scm.com/downloads) and is quite similar to Linux and macOS terminals, ensuring a consistent experience for everyone.
  - On **macOS**, we use the built-in **Terminal**.
  - On **Linux**, any terminal can be used.
- When opening the terminal, we typically see a message formatted as `user@computer-name:directory`. For example, the user might be `john`, the computer name `john-pc`, and the directory `~`, which refers to the user's home directory.
- To view the contents of the current directory:
```sh
dir
```
- To change the current directory:
```sh
cd Documents
```
- If the directory name has spaces, enclose it in double quotes:
```sh
cd "My Documents"
```
- To go back one directory level:
```sh
cd ..
```
- To create a new folder:
```sh
mkdir folder_name
```
- To delete a file:
```sh
rm file_name
```
- To delete a folder and its contents:
```sh
rm -r folder_name
```
- To copy a file:
```sh
cp file_name copy_name
```
- To move a file:
```sh
mv file destination
```
- To rename a file:
```sh
mv old_name new_name
```
- Files and folders have full paths. On Windows, for example:
```
C:\Users\john\Documents\hello.txt
```
- On Windows, to see the full path of the current directory:
```sh
pwd
```
- To create an empty file:
```sh
touch file_name
```
- To display the contents of a file:
```sh
cat file_name
```
- To write text to a file:
```sh
echo "testing" > file_name
```
- To create or edit files, you can use a text editor like `nano`:
```sh
nano file_name
```
- To save in `nano`, press `CTRL+O` and `Enter`.
- To exit `nano`, press `CTRL+X`.
