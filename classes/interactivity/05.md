# Git

## Section: Git

### Summary

- `THESIS.docx`, `THESIS_FINAL.docx`, `THESIS_REALLY_FINAL.docx` are all different versions of the same document. In programming, we are constantly creating versions and need to manage them without compromising our files and structure. Git is a version control software.

- Each git working directory is a repository with a complete history.

- Git stores the repository by tracking the differences between files over time, creating a step-by-step history from one version to the next.

- Before using git for the first time, you need to configure it:

```bash
git config --global user.name "John Doe"
git config --global user.email "johndoe@email.com"
```

- To initialize a git repository:

```bash
git init
```

- Any saved changes to files inside the repository directory are not automatically added to the git history. You must explicitly tell git which files and changes to track.

- To stage all files:

```bash
git add .
```

- To stage a specific file:

```bash
git add ./file_name
```

- To view what is currently staged:

```bash
git status
```

- Once files are staged, you can create a commit (a checkpoint in the repository history) with a specific message:

```bash
git commit -m "My commit message"
```

- After committing, the changes are recorded in the history and removed from the staging area.

- To view the commit history:

```bash
git log
```

### Exercise

- Step 1

    Using the terminal, create a folder called **project_git** inside the user's home directory. Then, turn this directory into a local git repository:

    ```bash
    mkdir ~/project_git
    cd ~/project_git
    git init
    ```

- Step 2

    Next, create a file named `myText.txt` and write the following two lines:

    ```
    I'm playing with Git!
    Hello, Git!
    ```

    Add these changes to the staging area:

    ```bash
    git add myText.txt
    ```

- Step 3

    Inside the **project_git** repository created in **Step 2**, edit the text file to:
    - Add a new line: "Git is very cool!"
    - Delete the first line

    Then, stage the updated file and commit the changes:

    ```bash
    git add myText.txt
    git commit -m "Updated myText.txt: added a line, removed the first line"
    ```

    Finally, check the modification history of your project:

    ```bash
    git log
    ```
